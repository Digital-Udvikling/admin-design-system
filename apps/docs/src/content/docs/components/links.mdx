title: Links
description: Styled text links with an optional external affordance.

import { Link } from "@aortl/admin-react";
import { IconHome, IconDownload } from "@tabler/icons-react";

## Examples

### Basic

:::example

```html
<a class="link" href="#">View order</a>
```

```tsx
<Link href="#">View order</Link>
```

:::

### With icon

:::example

```html
<a class="link" href="#"><i class="ti ti-home" aria-hidden="true"></i>Dashboard</a>
<a class="link" href="#">Export<i class="ti ti-download" aria-hidden="true"></i></a>
```

```tsx
<Link href="#" icon={IconHome}>
  Dashboard
</Link>
<Link href="#" iconTrailing={IconDownload}>
  Export
</Link>
```

:::

### External

:::example

```html
<a class="link link-external" href="https://example.com" target="_blank" rel="noopener noreferrer"
  >Open in inRiver</a
>
```

```tsx
<Link href="https://example.com" external>
  Open in inRiver
</Link>
```

:::

## Reference

### React

| Prop           | Type                                          | Default |
| -------------- | --------------------------------------------- | ------- |
| `external`     | `boolean`                                     | `false` |
| `icon`         | [`IconProp`](../../basics/conventions/#icons) | —       |
| `iconTrailing` | [`IconProp`](../../basics/conventions/#icons) | —       |
| `render`       | `ReactElement`                                | —       |

`external` adds the trailing ↗ and defaults `target="_blank"` + `rel="noopener noreferrer"`; passing either prop explicitly wins. It's independent of `iconTrailing`, so setting both renders two trailing markers. `render` puts the link styling on your own element, such as a router link (see [Conventions › `render`](../../basics/conventions/#render)). Plus native `<a>` attributes — `href` included, which this component does not supply.

### Vanilla

| Class / var             | Effect                                                                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `link`                  | Inline link colour, underline at `2px` offset, focus-visible ring; long URLs break. With a direct `<i>`/`<svg>`, inline-flex with a `0.25rem` gap |
| `link-external`         | Adds a `0.85em` ↗ via `::after`, masked from `currentColor`                                                                                       |
| `--link-external-arrow` | The arrow's mask image. Override to swap the glyph                                                                                                |

The ↗ is drawn in CSS, so it ships in both bundles with no icon-font dependency. `target` and `rel` are yours to write in vanilla. A plain link wraps with the surrounding text, and the ↗ stays on the line of its last word. A link with a direct-child `<i>` or `<svg>` wraps as one inline-flex box: the icon sits on the label's first line, doesn't shrink and isn't underlined. No wrapper class needed.

For blocks of HTML you can't annotate, [Prose](../prose/) styles bare `<a>` the same way.
