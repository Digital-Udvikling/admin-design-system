## Reference

### React

| Part            | Renders | Class           |
| --------------- | ------- | --------------- |
| `Timeline`      | `<ol>`  | `timeline`      |
| `Timeline.Item` | `<li>`  | `timeline-item` |

| Part            | Prop          | Type                                                                     | Default     |
| --------------- | ------------- | ------------------------------------------------------------------------ | ----------- |
| `Timeline`      | `numbered`    | `boolean`                                                                | `false`     |
| `Timeline`      | `horizontal`  | `boolean`                                                                | `false`     |
| `Timeline.Item` | `status`      | `"default" \| "info" \| "success" \| "warning" \| "danger" \| "current"` | `"default"` |
| `Timeline.Item` | `icon`        | [`IconProp`](../../basics/conventions/#icons)                            | —           |
| `Timeline.Item` | `marker`      | `ReactNode`                                                              | —           |
| `Timeline.Item` | `title`       | `ReactNode`                                                              | —           |
| `Timeline.Item` | `time`        | `ReactNode`                                                              | —           |
| `Timeline.Item` | `description` | `ReactNode`                                                              | —           |
| `Timeline.Item` | `classNames`  | [slots](../../basics/conventions/#classnames)                            | —           |

The indicator is a dot by default; `icon` replaces it with a glyph, and `marker` — which wins over `icon` — replaces it with the numbered variant's filled marker. `status` colours the dot, icon or marker: `success` for a done step, `danger` for a failed one, `current` in the primary ink. `current` also sets `aria-current="step"`; set it yourself on the vanilla `<li>`. `classNames` reaches the indicator, dot, marker, content, title, time and description slots.

Nothing here advances a step tracker: compute which item is `current` yourself. Plus native `<ol>` / `<li>` attributes.

### Vanilla

| Class                                                                                       | Effect                                                                                                        |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `timeline`                                                                                  | Marker-less `<ol>`                                                                                            |
| `timeline-item`                                                                             | Two-column grid: `1.5rem` indicator gutter, `0.75rem` gap, `1rem` of space beneath                            |
| `timeline-indicator`                                                                        | Centres the dot, icon or marker in the gutter, above the connector                                            |
| `timeline-dot`                                                                              | `0.625rem` dot in `border-strong`, ringed `3px` in `--surface-current`                                        |
| `timeline-content`                                                                          | Text column, `0.125rem` gap, shrinkable so long values wrap                                                   |
| `timeline-title`                                                                            | `text-sm` medium                                                                                              |
| `timeline-time`                                                                             | `text-xs` muted, tabular figures                                                                              |
| `timeline-description`                                                                      | `text-sm` muted                                                                                               |
| `timeline-item-info` `timeline-item-success` `timeline-item-warning` `timeline-item-danger` | Status colour on the dot, icon or marker                                                                      |
| `timeline-item-current`                                                                     | Primary ink on the dot, icon or marker; pair with `aria-current="step"`                                       |
| `timeline-numbered`                                                                         | Widens the gutter to `1.75rem` for a marker                                                                   |
| `timeline-marker`                                                                           | `1.75rem` circle in `surface-strong`, `text-xs` semibold tabular figures, ringed `3px` in `--surface-current` |
| `timeline-horizontal`                                                                       | Items become equal-width grid columns, indicator above centred content                                        |

The connector is drawn as a `::before` on each item except the last, so it stops at the end of the rail without any extra markup. Dot and marker rings and the icon backing mask the line in `var(--surface-current, var(--color-surface))`. Filled containers such as cards, dialogs, the navbar and the sidebar set `--surface-current` to their fill; set it next to the background of any other filled container that hosts a timeline, for example `--surface-current: var(--color-info-muted)`.

`timeline-horizontal` composes with `timeline-numbered` for a step tracker, and re-runs the connector along the indicator row. Columns are equal width, and as wide as the widest label when the rail is sized to its content, so the connector lands on each indicator's centre.
