import { Switch } from "@aortl/admin-react";

## Examples

### Default

:::example

```html
<input type="checkbox" role="switch" class="switch" aria-label="Off" />
<input type="checkbox" role="switch" class="switch" aria-label="On" checked />
```

```tsx
<Switch aria-label="Off" />
<Switch aria-label="On" defaultChecked />
```

:::

### With a label

:::example

```html
<label>
  <input type="checkbox" role="switch" class="switch" checked />
  Email notifications
</label>
```

```tsx
<label>
  <Switch defaultChecked />
  Email notifications
</label>
```

:::

### Disabled

:::example

```html
<input type="checkbox" role="switch" class="switch" aria-label="Disabled" disabled />
<input type="checkbox" role="switch" class="switch" aria-label="Disabled, on" disabled checked />
```

```tsx
<Switch aria-label="Disabled" disabled />
<Switch aria-label="Disabled, on" disabled defaultChecked />
```

:::

## Reference

### React

| Part           | Renders  | Class          |
| -------------- | -------- | -------------- |
| `Switch`       | `<span>` | `switch`       |
| `Switch.Thumb` | `<span>` | `switch-thumb` |

Wraps [Base UI Switch](https://base-ui.com/react/components/switch): `checked` / `defaultChecked` / `onCheckedChange`, `name`, `required`, `disabled`. It renders a `<span role="switch">` with a hidden input for form submission. `Switch` supplies its own thumb; pass `children` only to replace it. Plus native `<span>` attributes.

For a choice submitted with a form, use a [Checkbox](../checkboxes/).

### Vanilla

| Class          | Effect                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------- |
| `switch`       | `2.25rem` × `1.25rem` track, full radius, `border-strong` off with a `text-muted` edge / primary on |
| `switch-thumb` | `1rem` circle with a shadow, paper off and `primary-content` on, sliding `1rem` when checked        |

Works two ways with identical output. On a native `<input type="checkbox" role="switch">` the appearance is reset and the thumb drawn as a `::before`, keyed off `:checked` — no `switch-thumb` element needed. On an element with `role="switch"` the states come from `[data-checked]`, `[data-unchecked]` and `[data-disabled]`, and the thumb is a real `switch-thumb` child; that's what React emits. Write `role="switch"` yourself on the native input, otherwise it announces as a checkbox.

A wrapping `<label>` is laid out for you: inline row, `0.75rem` gap (wider than a checkbox's, since the track is wider), pointer cursor, the whole row dimmed to 50% when disabled. The track takes the height of one line (`1lh`), so it sits on the label's first line. Pair it with [`field-row`](../fields/#inline-label) for a label on the same line as the control.

`aria-invalid="true"`, `data-invalid`, `:user-invalid` and an enclosing `field[data-invalid]` give an off `switch` a danger edge.

A switch applies its change immediately. For something that only takes effect on submit, use a [checkbox](../checkboxes/).
