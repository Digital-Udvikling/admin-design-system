### Components at reading size

:::example

```html
<div class="prose prose-lg">
  <p>The invoice this refund applies to:</p>
  <div class="prose-exclude">
    <div class="card">
      <div class="card-body">INV-2041 · Annual plan · renewed 12 days ago</div>
    </div>
  </div>
  <p>The refund posts within 5–7 business days.</p>
</div>
```

```tsx
<Prose size="lg">
  <p>The invoice this refund applies to:</p>
  <Prose.Exclude>
    <Card>INV-2041 · Annual plan · renewed 12 days ago</Card>
  </Prose.Exclude>
  <p>The refund posts within 5–7 business days.</p>
</Prose>
```

:::

### Embedded components

A component inside rendered HTML goes in `prose-exclude`, so `.prose` doesn't add list markers or block margins to its elements.

:::example

```html
<div class="prose">
  <p>The order moved through these steps:</p>
  <div class="prose-exclude">
    <ol class="timeline">
      <li class="timeline-item timeline-item-success">
        <span class="timeline-indicator"><span class="timeline-dot"></span></span>
        <div class="timeline-content">
          <div class="timeline-title">Order shipped</div>
          <div class="timeline-time">14:32 · today</div>
        </div>
      </li>
      <li class="timeline-item">
        <span class="timeline-indicator"><span class="timeline-dot"></span></span>
        <div class="timeline-content">
          <div class="timeline-title">Order placed</div>
          <div class="timeline-time">14:28 · today</div>
        </div>
      </li>
    </ol>
  </div>
  <p>Refunds are possible until it is delivered.</p>
</div>
```

```tsx
<Prose>
  <p>The order moved through these steps:</p>
  <Prose.Exclude>
    <Timeline>
      <Timeline.Item status="success" title="Order shipped" time="14:32 · today" />
      <Timeline.Item title="Order placed" time="14:28 · today" />
    </Timeline>
  </Prose.Exclude>
  <p>Refunds are possible until it is delivered.</p>
</Prose>
```

:::

### Consecutive components

:::example

```html
<div class="prose">
  <p>Before refunding an annual plan:</p>
  <div class="prose-exclude">
    <div class="alert alert-warning" role="alert">Refunds after 30 days need finance approval.</div>
  </div>
  <div class="prose-exclude">
    <div class="card">
      <div class="card-body">
        <h3 class="card-title">INV-2041</h3>
        <p class="card-description">Annual plan · renewed 12 days ago</p>
      </div>
    </div>
  </div>
  <p>The refund posts within 5–7 business days.</p>
</div>
```

```tsx
<Prose>
  <p>Before refunding an annual plan:</p>
  <Prose.Exclude>
    <Alert variant="warning">Refunds after 30 days need finance approval.</Alert>
  </Prose.Exclude>
  <Prose.Exclude>
    <Card title="INV-2041" description="Annual plan · renewed 12 days ago" />
  </Prose.Exclude>
  <p>The refund posts within 5–7 business days.</p>
</Prose>
```

:::

### Injecting a rendered HTML string

```html
<!-- server renders markdown → html, then: -->
<div class="prose">{{ renderedHtml }}</div>
```

```tsx
<Prose dangerouslySetInnerHTML={{ __html: renderedHtml }} />
```

<Callout variant="danger">

Sanitize untrusted HTML before injecting it. The wrapper styles markup; it does not filter it.

</Callout>

## Reference

### React

| Part            | Renders             |
| --------------- | ------------------- |
| `Prose`         | `div.prose`         |
| `Prose.Exclude` | `div.prose-exclude` |

| Prop   | Type           | Default |
| ------ | -------------- | ------- |
| `size` | `"md" \| "lg"` | `"md"`  |

`size` is on `Prose` only; `"lg"` adds `prose-lg`. A nested `Prose` renders at its own size. Plus native `<div>` attributes.

### Vanilla

| Class           | Effect                                                                                                                                                                                                                                                                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `prose`         | Restores element styling inside the wrapper: `text-sm` on a `1.625` line, `1em` block rhythm, a heading scale of its own, muted list markers, GFM task-list checkboxes in place of bullets, underlined links, `<code>` as the [`code`](../code-blocks/#inline) chip, `<kbd>` key chips, a scrolling `<pre>`, a bordered `<blockquote>`, and the table look from [Tables](../tables/) |
| `prose-lg`      | With `prose`: the reading size for long-form text. `text-base` on a `1.7` line, `1.25em` block rhythm, a steeper heading scale and a `45em` line length on text blocks. Tables, `<pre>` and `prose-exclude` subtrees keep UI size; a `.prose` nested inside renders at the default size                                                                                              |
| `prose-exclude` | A subtree `.prose` leaves unstyled, for components embedded in rendered HTML. It resets to UI type (`text-sm`, `1.5` line height) and, as a direct child of `.prose`, takes the block gap. A `.prose` inside it styles its own content again                                                                                                                                         |

The global reset strips margins, list markers, and link styling from bare elements so admin chrome stays neutral, which leaves backend-rendered HTML unstyled. This class re-establishes it for one region, from the same semantic tokens, so it follows dark mode. First and last children keep their outer margins collapsed.

Each cell gives the size, then the space above / below.

| Element         | `prose`                                      | `prose-lg`                           | Line-height |
| --------------- | -------------------------------------------- | ------------------------------------ | ----------- |
| `<h1>`          | `1.714em` (24px), 32 / 16px                  | `2em` (32px), 40 / 16px              | 1.25        |
| `<h2>`          | `1.286em` (18px), 32 / 12px                  | `1.5em` (24px), 42 / 12px            | 1.35        |
| `<h3>`          | `1.143em` (16px), 24 / 8px                   | `1.25em` (20px), 32 / 12px           | 1.4         |
| `<h4>`          | `1em` (14px), 20 / 8px                       | `1em` (16px), 24 / 8px               | 1.45        |
| `<h5>`, `<h6>`  | `0.857em` (12px), 20 / 8px, uppercase, muted | `0.857em` (13.7px), 23 / 9px         | 1.5         |
| Body            | 14px, `1em` (14px) between blocks            | 16px, `1.25em` (20px) between blocks | 1.625 / 1.7 |
| Inline `<code>` | `0.85em`                                     | `0.875em`                            | —           |
| Line length     | none                                         | `45em` (720px)                       | —           |

Heading sizes and the spacing around text are em of the text, so a wrapper that changes the font size inside `.prose` scales them. The gap around tables, `<pre>` and `prose-exclude` subtrees, and the line length, are fixed on `.prose`. The line length applies to paragraphs, headings, captions, definition lists, and list items and quotes that hold no code, table or excluded subtree.

Headings are semibold and balance their lines; paragraphs and list items wrap with `text-wrap: pretty`. A heading's bottom margin sets the gap to the block it leads, and a heading that follows another keeps its top margin. Table cells keep the UI's `1.5` line.

Every descendant rule is wrapped in `:where()`, so a consumer's own `.prose a { … }` wins on specificity without `!important`.

Anchors with `.btn`, `<pre class="code-block">` and `<table class="table">` keep their own styling inside `.prose`. Any other component goes in `prose-exclude`.

When you control the markup, reach for the dedicated components instead: [Link](../links/), [Table](../tables/), [Code blocks](../code-blocks/).
