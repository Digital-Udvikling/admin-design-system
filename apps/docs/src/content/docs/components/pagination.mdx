### Links (routing libraries)

In React, spread `renderItem`'s second argument onto your router's link. It carries the `_ao-` classes, so don't write `className="pagination-link"` by hand.

:::example

```html
<nav class="pagination" aria-label="Pagination">
  <ul>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=1" aria-label="Previous page">
        <i class="ti ti-chevron-left" aria-hidden="true"></i>
      </a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=1" aria-label="Page 1">1</a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=2" aria-current="page" aria-label="Page 2">2</a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=3" aria-label="Page 3">3</a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=4" aria-label="Page 4">4</a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=5" aria-label="Page 5">5</a>
    </li>
    <li class="pagination-item">
      <a class="pagination-link" href="?p=3" aria-label="Next page">
        <i class="ti ti-chevron-right" aria-hidden="true"></i>
      </a>
    </li>
  </ul>
</nav>
```

```tsx
<Pagination
  page={2}
  total={5}
  onPageChange={() => {}}
  renderItem={(item, { children, ...props }) => {
    if (item.type === "ellipsis") return <span {...props}>{children}</span>;
    const disabled = item.type !== "page" && item.disabled;
    return (
      <a {...props} href={disabled ? undefined : `?p=${item.page}`}>
        {children}
      </a>
    );
  }}
/>
```

## Reference

### React

| Prop            | Type                                                              | Default        |
| --------------- | ----------------------------------------------------------------- | -------------- |
| `page`          | `number`                                                          | — (required)   |
| `total`         | `number`                                                          | — (required)   |
| `onPageChange`  | `(page: number) => void`                                          | — (required)   |
| `siblingCount`  | `number`                                                          | `1`            |
| `boundaryCount` | `number`                                                          | `1`            |
| `previousIcon`  | [`IconProp`](../../basics/conventions/#icons)                     | chevron        |
| `nextIcon`      | [`IconProp`](../../basics/conventions/#icons)                     | chevron        |
| `renderItem`    | `(item: PaginationItem, props: PaginationItemProps) => ReactNode` | —              |
| `classNames`    | [slots](../../basics/conventions/#classnames)                     | —              |
| `aria-label`    | `string`                                                          | `"Pagination"` |

Always controlled: `page` is 1-based and clamped into `[1, total]`, and the component never holds page state. `siblingCount` is how many pages flank the current one, `boundaryCount` how many stick to each end; a gap of exactly one page renders that page instead of an ellipsis. `classNames` covers `item`, `link`, `ellipsis`. Icons render at `1em`. At the first or last page, previous/next get `aria-disabled="true"` without `disabled`, so a focused control keeps focus.

`renderItem` is called once per item and replaces the default `<button>`, the hook a routing library's `<Link>` needs. The four `item.type` values are `"page"`, `"previous"`, `"next"`, `"ellipsis"`. Its second argument, `PaginationItemProps`, holds what the default renderer would set: `className` (the `_ao-` classes plus `classNames`), `aria-label`, `aria-current`, `aria-disabled` or `aria-hidden`, and `children` (the number, icon or `…`). `getPaginationItems` is exported separately if you want the range without the markup; it is pure and safe to call during render. The default renderer attaches click handlers, so it needs a Client Component; from a Server Component, pass a `renderItem` that returns links.

Plus native `<nav>` attributes.

### Vanilla

| Class                 | Effect                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `pagination`          | Root `<nav>`. Turns its direct `<ol>`/`<ul>` into an inline-flex row, `0.25rem` gap, no markers |
| `pagination-item`     | One `<li>`                                                                                      |
| `pagination-link`     | Page control: `2rem` square minimum, `0.375rem` radius, `text-sm`, transparent until hover      |
| `pagination-ellipsis` | Muted `…` occupying the same `2rem` box                                                         |

`pagination` itself sets nothing — it exists to scope the list. `pagination-link` marks the current page from `aria-current="page"`. It dims for `[disabled]`, `[aria-disabled="true"]` and `[data-disabled]`, so an anchor that can't be a real `<button>` still reads as inactive. The React range logic has no vanilla equivalent — compute it server-side.
